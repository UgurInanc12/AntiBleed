## graphify

This project has a code knowledge graph at `graphify-out/` (495 nodes,
753 edges). The graphify MCP tools can query it with
`project_path: "D:/Hermes/ANTI_BLEED_MIC"`; the `graphify` CLI reaches the same data.

The graph is a fast map of how the code fits together. `god_nodes` shows the
core abstractions, `query_graph` answers how a feature works, `get_neighbors`
shows every caller around a symbol, and `shortest_path` traces connections
across modules (with `undirected: true` when no directed path exists). One graph
read can replace several file walks and uses a fraction of the context.

The graph covers code. Status, phases, and decisions remain in the project's
Markdown files. After code changes, `graphify update .` (AST only, seconds)
keeps the graph current.
